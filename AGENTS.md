# AGENTS.md

Flex-рецепти пакетів Laba. Як усе влаштовано — у `README.md`.

Відповідай і пиши документацію українською; `manifest.json`, yaml-коментарі й `bin/` — англійською.

- Правиться лише джерело `laba/<package>/<version>/`. `r/` і список `recipes` в `index.json` генерує
  `bin/compile`, руками їх не змінюй; після зміни джерела — `bin/compile`, потім `bin/compile --check`.
- Опублікованої версії рецепта не змінюй: нову поведінку — новою версією (копія попередньої).
  Нова версія — лише коли змінюється те, що рецепт створює (конфіг, env), а не на кожен реліз пакета.
- Конфіг рецепта має проходити дерево конфігу бандла тієї версії, для якої рецепт.
- Таблицю версій у `README.md` онови разом із новим рецептом.
- `bin/` — Python 3 лише зі стандартною бібліотекою.
- Не комітити без явного прохання.
